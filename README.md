# Stella Protocol · NASA Space Apps Challenge 2026

Challenge: **Space Mission Design Game**. Dates: Saturday, November 14 and Sunday, November 15, 2026.

## ▶ Play now: https://stella-protocol.vercel.app

Runs in any modern browser (desktop or phone). The game opens in English; the **Español** button switches language.

> This is the English repository. A Spanish twin exists with the same content.

## Folder structure

| Folder | Contents |
|---|---|
| `app/` | Game source code (React + Vite + Three.js). Built from scratch during the hackathon. |
| `research/` | NASA research: how missions work, crew and spacecraft risks, analyzed missions and sources. |
| `docs/game-design/` | Game design: mechanics, screens, balance. |
| `docs/pitch/` | Pitch script and Space Apps project page text. |
| `assets/models` · `textures` · `audio` · `images` | Original or openly licensed assets (CC0 or public domain). Always note the source. |
| `presentation/video` · `screenshots` | 30-second video and screenshots for the submission. |
| `team/` | Task split, 48-hour schedule and team notes. |

## Team rules
- All code is written during the hackathon. Nothing is copied from earlier projects.
- Only openly licensed assets are used, and every source is credited.
- The NASA logo is not used.
